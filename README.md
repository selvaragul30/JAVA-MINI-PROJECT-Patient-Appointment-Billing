# JAVA-MINI-PROJECT-Patient-Appointment-Billing
Build a Java console app to manage patients, doctors, appointments, consultations, and billing.

Problem Statement: Build a Java console app to manage patients, doctors, appointments,
consultations, and billing.

HOW TO RUN/COMPILE:
Open Eclipse → File → New → Java Project.
Enter project name: HospitalManagementSystem → click Finish.
Right-click src → New → Class.
Create 8 separate Java files: Patient, Doctor, Appointment, Prescription, Consultation, Invoice, Payment, HospitalManagementSystem.
Copy the corresponding code from your uploaded file into each Java file and press Ctrl + S.
Open HospitalManagementSystem.java → right-click → Run As → Java Application.
Enter your choices in the Console and press Enter.
